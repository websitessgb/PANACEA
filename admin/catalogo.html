Cómo usarlo

  1. Edita directamente los precios, moneda o disponibilidad en la tabla.
  2. Para cambiar una fotografía, pulsa Reemplazar imagen en la fila del producto. Se subirá a su carpeta de categoría.
  3. También puedes exportar el catálogo a CSV, modificar muchos precios en Excel y volver a importarlo. Conserva la columna id para identificar cada producto.
  4. Cuando termines, introduce tu token de GitHub y pulsa Revisar y publicar cambios. Se mostrará un resumen antes de enviar los cambios al repositorio.

Consejo: antes de una actualización grande, descarga una copia CSV del catálogo actual.
